### О проекте

Персональная стартовая страница (Bio Link / Linktree Alternative), выполненная в темном минималистичном стиле с элементами интерфейса терминала. Страница объединяет все медиа-ресурсы, социальные сети и аудио-профиль.

#### Функциональные особенности
* **Анимированный экран загрузки:** Лоадер с процентным индикатором (0–100%) и анимацией системной инициализации.
* **Часовой пояс реального времени:** Отображение текущего времени Киева (`Europe/Kyiv`) с помощью `Intl.DateTimeFormat`.
* **Терминальный стиль:** Командная строка с мерцающим курсором и индикатором статуса.
* **Интерфейс:** Эффекты размытия (Glassmorphism), анимация мерцания, кастомный SVG-фавикон и адаптивная сетка под мобильные устройства.
